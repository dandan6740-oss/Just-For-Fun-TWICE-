# TWICE Fan Website

A responsive, interactive fan-made TWICE website built with:
- HTML
- CSS
- Vanilla JavaScript

No Java, C, or C++ is used.

## How to run
1. Keep `index.html`, `style.css`, and `script.js` in the same folder.
2. Double-click `index.html`, or open it with a browser.
3. Internet is only needed for the Google Fonts import and the official TWICE website link.

## Interactive features
- Smooth scrolling navigation
- Light/dark mode with saved preference
- Interactive member cards with modal popups
- Music/era selector
- Cursor glow effect
- Scroll reveal animations
- Responsive mobile layout

## Important
The member visual cards currently use stylized initials rather than copyrighted promotional photos. You can replace each `.member-photo` background with licensed/official images if your assignment permits.
